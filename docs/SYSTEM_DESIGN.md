# Design System & Style Guide

**Short Description:** Colors, fonts, spacing, and component rules.

## Overview
- **Theme:** Artistic Flair (High-contrast, bold borders, brutalist/technical aesthetic).
- **Primary Colors:** White (#fdfdfc), Black (#1a1a1a), USDA Green (#15803d), USDA Blue (#0369a1).
- **Typography:** Inter (sans-serif) with bold/black weights for headers.
